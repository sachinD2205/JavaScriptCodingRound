Problem Statement
You are tasked with creating a function that counts the total number of comments in a nested comment thread, similar to what you might find on platforms like Reddit, Twitter, or any discussion forum. Each comment can have multiple replies, and those replies can themselves have replies, creating a tree-like structure.

Requirements
Write a function called countComments.

Arguments
comments: An array of objects
Each comment object would have the following structure:

{
  // The content of the comment
  text: String,
  // An array of reply objects that have the same structure
  replies: Array
}
Each reply object follows the same structure, potentially creating deep nesting.

Returns
Returns a single number representing the total count of all comments (including the root comment and all nested replies at any depth).
Throw an error if circular reference is found.
Important
Your solution should

Your solution should handle any level of nesting properly
Your solution should have optimal time and space complexity
The root comment itself (counts as 1)
Think about how to handle circular references
If malformed comments object data is passed (missing keys)
Examples
const comments = {
  text: "some comment",
  replies: [
    { text: "some comment 1", replies: [] },
    { text: "some comment 2", replies: [] },
    { text: "some comment 3", replies: [
        { text: "some comment 5", replies: [] }
      ]
    }
  ]
};

// Should return 5
countComments(comments);
const comments = {
  text: "root comment",
  replies: []
};

// Should return 1
countComments(comments);
const comments = {
  text: "level 1",
  replies: [{
    text: "level 2",
    replies: [{
      text: "level 3",
      replies: [{
        text: "level 4",
        replies: []
      }]
    }]
  }]
};

// Should return 4
countComments(comments);
